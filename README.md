# RoboSats Monitor

Get a bird's-eye view of RoboSats orders live.

satsmonitor.org

# Install

Tor:
```
sudo apt install tor
sudo systemctl start tor
```

To install the package, do one of the following:

## venv

```
python3 -m venv .venv
source .venv/bin/activate

pip install .
```

## uv

```
uv sync
```
